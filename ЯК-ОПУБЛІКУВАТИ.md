# Як отримати постійне посилання (безкоштовно, ~10 хвилин)

Після цих кроків сайт живе на адресі виду `https://svidomyi-vybir.onrender.com`
— працює 24/7, навіть коли ваш комп'ютер вимкнений, без жодних сторінок-перешкод.

## Крок 1. Акаунт GitHub (2 хв)

1. Відкрийте https://github.com/signup
2. Введіть email, пароль, ім'я → підтвердіть email (прийде лист)
3. Зверху справа натисніть **«+»** → **New repository**
4. Назва: `svidomyi-vybir` → **Create repository** (нічого більше не змінюйте)

## Крок 2. Надіслати код проєкту на GitHub

Найпростіше — через програму GitHub Desktop:

1. Встановіть https://desktop.github.com
2. Увійдіть у свій GitHub-акаунт (відкриється вікно браузера)
3. **File → Add local repository** → оберіть папку:
   `C:\Users\pavlivartem18\.zcode\workspace\default\org-site`
4. Натисніть **Publish repository**

## Крок 3. Акаунт Render і запуск сайту (5 хв)

1. Відкрийте https://render.com → **Get Started** → **Sign up with GitHub**
2. На дашборді: **New +** → **Web Service** → знайдіть `svidomyi-vybir` → **Connect**
3. Заповніть:
   - Runtime: **Node**
   - Build Command: `npm run build`
   - Start Command: `npm start`
   - Instance Type: **Free**
4. Натисніть **Create Web Service** і почекайте 3–5 хвилин
5. Готово! Посилання вгорі сторінки сервісу (`.onrender.com`) — кидайте всім

## Що варто знати про безкоштовний Render

- Якщо на сайті немає відвідувачів ~15 хвилин, сервер «засинає».
  Перше відкриття після цього триває до 50 секунд — це нормально.
- Дані (новини, події, користувачі) зберігаються у файлі на диску сервісу
  і скидаються до початкових при кожному оновленні деплою.
  Коли сайт «приживеться» — підкажу, як безкоштовно підключити MongoDB Atlas,
  тоді дані стануть постійними.

## Локальний запуск (для редагування)

```
cd org-site\server && npm start      # API + зібраний сайт: http://localhost:4000
cd org-site\client && npm run dev    # dev-режим: http://localhost:5173
```
