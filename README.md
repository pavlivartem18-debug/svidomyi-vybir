# Платформа Молодіжного обʼєднання «Свідомий Вибір»

Повнофункціональна цифровая платформа ГО: публічний сайт + система управління членством, засіданнями, поіменними голосуваннями та опитуваннями. React + Tailwind CSS (фронтенд), Node.js + Express (бекенд), JWT-автентифікація.

**Дані**: якщо задано змінну середовища `MONGODB_URI` — MongoDB Atlas, інакше локальний JSON-файл (`server/data/db.json`). Зображення — локально (`server/uploads/`).

## Можливості

- **Публічна частина**: головна, про нас, події (календар + фільтри + реєстрація), новини (пошук, категорії, зображення), волонтерство, контакти, розсилка, укр/англ + темний режим.
- **Реєстрація та ролі**: реєстрація з фото, прізвищем і описом → одразу доступ до кабінету; статус «члена організації» призначає адміністратор (верифікація). Ролі: Admin / Deputy / Member / Guest.
- **Засідання**: порядок денний (питання з відповідальними і статусами), реєстрація участі (беру/не беру/не визначився), список учасників.
- **Поіменні голосування**: адмін створює і розпочинає голосування; члени голосують ЗА/ПРОТИ/УТРИМАВСЯ (один голос, змінити не можна); результати в реальному часі з поіменною таблицею; історія голосів у кабінеті.
- **Опитування**: варіанти з підрахунком відсотків, доступні верифікованим членам.
- **Рейтинги і відгуки**: рейтинг активності (засідання 40% + голосування 40% + опитування 20%, рахується на сервері), відгуки членів один про одного з оцінкою 1–5.
- **Сповіщення**: дзвіночок у шапці (нова реєстрація, верифікація, нове засідання, початок/завершення голосування, опитування, відгук).
- **Адмінпанель (13 розділів)**: статистика з графіками за 6 місяців, верифікація учасників, користувачі (блокування/ролі), засідання, голосування (старт/стоп/результати), опитування, новини, події, відгуки, волонтери, повідомлення, підписники, журнал дій адміністратора.
- **Експорт CSV**: список членів, поіменні результати голосувань, результати опитувань.


## Швидкий старт

```bash
# 1. Бекенд (порт 4000)
cd server
npm install
npm start

# 2. Фронтенд (порт 5173) — в новому терміналі
cd client
npm install
npm run dev
```

Сайт: http://localhost:5173 · API: http://localhost:4000

## Що реалізовано

- **Автентифікація**: реєстрація з інтересами, верифікація email (токен), логін/логаут, профіль з редагуванням і зміною пароля, скидання пароля, ролі Admin/Member/Guest, JWT.
- **Новини**: CRUD у адмінці (з завантаженням зображень), категорії, пошук, сторінка новини. Публікація новини «розсилає» сповіщення підписникам (прототип — у консоль сервера).
- **Події**: CRUD у адмінці, календар на місяць із позначкою днів, фільтри за категорією та датами, реєстрація користувачів на події з лімітом місць, скасування реєстрації.
- **Сторінки**: Home (герой, новини, події, статистика, розсилка), About (місія, бачення, команда), Events, News, Volunteer (форма), Contact (форма), Dashboard (профіль + мої події), Admin (7 вкладок).
- **Додатково**: підписка на розсилку, двомовність УКР/ENG, темний режим, адаптивна верстка (мобільне меню), соцмережі у футері.

## Прототипні спрощення

- Листи (верифікація, скидання пароля, сповіщення) виводяться в **консоль сервера**, а посилання також повертаються в відповіді API — їх можна одразу відкрити.
- Замість Cloudinary зображення зберігаються локально й віддаються з `/uploads`.

## Структура

```
org-site/
├─ server/            # Express API
│  ├─ src/server.js   # усі маршрути
│  ├─ src/db.js       # файлове сховище (замінити на MongoDB тут)
│  ├─ src/auth.js     # JWT, middleware
│  ├─ src/mailer.js   # «надсилання» листів (прототип)
│  └─ src/seed.js     початкові дані
└─ client/            # React + Vite + Tailwind v4
   └─ src/pages/      # усі сторінки
```
